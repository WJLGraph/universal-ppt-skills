# 两阶段 Prompt 模板库

> Stage 1→2 用模板一（素材→大纲），用户确认后 Stage 4 用模板二（大纲→PPT）。可整段复制使用，方括号处按需替换。

## 模板一：素材精读 → 汇报大纲（先要大纲，不要直接生成 PPT）

```text
请你作为[研究生文献汇报/项目汇报/课程制作]助手，精读我提供的[论文 PDF/报告/素材]。

请先不要生成 PPT，而是先输出一份汇报大纲，要求包括：

1. 基本信息：标题、来源/venue、年份、领域
2. 背景：该领域要解决什么问题、为什么重要、现有方法/做法有哪些不足
3. 核心问题：本次具体解决什么、动机是什么
4. 方法/方案：核心思想、框架结构、关键公式或流程、与已有方式的区别
5. 实验/论证：数据集/样本、对照、评价指标、主要设置
6. 关键结果：最重要的 2-3 个结果，每个标注对应原文的图/表/章节位置
7. 创新点：理论/方法/应用层面的贡献
8. 不足与局限：假设、缺陷、泛化性、改进方向
9. 适合 N 页 PPT 的页面结构建议（每页给一个结论式标题）

注意：
- 不要编造素材中没有的内容；
- 关键结论尽量标注来源位置（章节/图表）；
- 每页标题写成结论句（action title），而不是章节名；
- 输出要适合后续直接生成中文汇报 PPT。
```

## 模板二：大纲 → PPT（已确认大纲后）

```text
请基于上面确认的汇报大纲，生成一份 N 页 PPT。

要求：
1. 用于[研究生组会/答辩/述职/教学/党政汇报/竞赛路演]场合，时长约 X 分钟；
2. 风格：先给我 2-3 个候选风格（附一句推荐理由），我确认后锁定执行；
3. 每页标题是结论句（action title），只看标题就能听懂全篇；
4. 每页正文不超过 5 个 bullet，每个不超过 1.5 行；
5. 方法页用流程图/结构图表达，不用纯文字；
6. 结果页突出关键结论，直接在图表上标注重点，不堆数字；
7. 两个高密度页之间插入喘息页（大字结论或分节页）；
8. 为每一页添加 80-120 字中文讲稿；
9. 图表遵循顶刊风格：细线、低饱和、直接标注、涨红跌绿；
10. 输出 [PPTX/HTML/PDF]，渲染路径按我的需求选择。
```

## 模板三：要求套用学校/企业模板时

```text
我上传了统一 PPT 模板。请先分析模板的版式（layouts）和占位符（placeholders），
按模板母版生成 PPT：标题进标题占位符、正文进正文占位符、图片进图片占位符。
不要把文字直接覆盖在背景图上。
模板有 4 个槽位而实际内容只有 3 项时，删除多余槽位的整个元素组。
```

## 模板四：审计/改进已有 PPT

```text
请读取这份 PPTX，先做内容盘点（逐页：标题+要点+版式），输出诊断报告：
1. 哪些页标题不是结论式（给出改写建议）；
2. 哪些页文字超载/溢出/版式重复；
3. 哪些图表裸奔（无标注、默认配色）；
4. 有哪些"AI 生成味"问题（装饰线、色条、占位符遗留）；
5. 引用是否完整、讲稿是否齐全。
先给诊断，经我确认后再逐页修改。
```

## 模板五：AI 生图路径的风格锁定追加段（R4）

```text
请先用生图模型产出第 1 页样张，通过后我确认再继续。
第 2 页起每页以第 1 页成品为参考图，prompt 中显式声明：
"continuing EXACT visual style from reference image, SAME palette, SAME typography"，
并逐页串行生成，禁止并行。
```

## 模板六：多文献综述大纲（>5 篇）

```text
请围绕[研究主题]综合以下 N 篇文献，输出综述大纲（不要逐篇罗列）：
1. Themes：3-6 条贯穿文献集的研究方向；
2. Convergences：多篇一致认同的发现；
3. Disagreements：结论冲突或方法分歧；
4. Gaps：文献集体尚未解决的问题；
5. 每部分给 1-2 页 PPT 结构建议，标注支撑文献。
文献过散无法综合时，直接说明而不是硬凑主题。
```

## 模板七：图片式 PPT → 可编辑 PPTX（R8）

```text
我提供的是[图片式 PPT/扫描页/课程截图]，请还原为对象级可编辑的 PPTX：
1. 逐页把版面拆成 3-5 个语义区（标题/文本/图形/表格/注记），逐区重建；
2. 可测量的圆、卡片、连接线、箭头一律用原生形状重建——细箭头用一个连接线形状、实心箭头用一个箭头形状（文字放箭头内），禁止"直线+三角形"拼箭头，禁止把整张图拍平成一张图片；
3. 文字读图提取后按原层级重建文本框；
4. 公式必须用公式引擎渲染，引擎不可用就停下来问我，不要用模糊截图糊弄；
5. 真正复杂的局部插画/照片可保留为位图，交付时注明哪些还是图片；
6. 每页渲染图与原图并排对比自查：结构无遗漏、无新增幻觉元素，通过后再组装。
```

## 模板八：风格定制品（无合适预设时）

```text
没有现成风格匹配我的需求。请按"四件套"现场定制一个命名风格并给我预览：
1. 色板：主色 + 1-2 辅色 + 强调色（给精确 hex，主色承担 60-70% 视觉权重）；
2. 字族搭配：中文字族 + 西文/数字伴侣字体，字号层级；
3. 视觉母题：一个贯穿全 deck 的复用元素（如圆角卡片/圆底图标/特定图形语言）；
4. 明暗基调：深浅三明治（深色封面+浅色内容）或全深/全浅。
我的主题是[主题]，情绪关键词是[关键词]。确认后把这套规格写入视觉规格卡并全 deck 执行。
```
