# 交付证据块模板（Stage 5 必填，直接照抄填空）

> 交付时不许只写"QA 已通过"。下面这一块**必须原样出现在交付说明里**，其中标记【不可豁免】的字段缺一个就算流程违规。脚本原始输出不许概括、不许改写、不许只写"已检查"。

## 1. 交付口播（用户第一眼看到的，控制在 10 行内）

```text
成品：<文件名>  （路径：computer://...）
页数：N 页  ·  模式：A-F（<场景判定一句话>）  ·  风格：<风格名>  ·  渲染路径：R1-R8
视觉页：k/N = xx%（含图片/图表/表格的页面）  ·  连续非视觉页：0
一句话结论：<这份 deck 想让听众记住的那个判断>
```

## 2. 不可豁免字段（逐条填，缺即违规）

| 字段 | 填什么 | 来源 |
| --- | --- | --- |
| 大纲确认证据 | 抄用户确认原话（≥8 字） | `work/deck-spec.json` → `confirm_evidence` |
| 风格确认证据 | 用户锁定的风格名 + 确认原话 | `deck-spec.json` → `style_name` / `style_confirmed` |
| QA 脚本原始输出 | 完整 `qa_output.txt` 内容（含每条 PASS/FAIL） | `scripts/deck_qa.py` 实跑结果 |
| FAIL/WARN 处理说明 | 每条 FAIL 修了什么、WARN 为何可接受 | 上一轮 vs 最后一轮的输出对比 |
| 每张图的来源 | `文件 → PDF 页码 + Figure 号`（论文原图）/ `docs 素材路径`（素材图）/ `来源：自绘 + reason`（自造图，须说明素材为何没有对应图） | `work/figures.json` |
| **论文原图使用情况** | 论文清单共 N 个 Figure：已上片哪几个（页码 → Figure 号）、未上片哪几个 + 各一句理由、自绘图几张及用途 | `work/paper-figures.json` + `deck-spec.json → unused_figures_reason` |
| 渲染预览可用性 | "已渲图逐页目检（工具：X）" 或 "**渲染预览不可用**，已用程序化检查 + 资产裁剪拼图 + 文本/形状审查替代" | Stage 5 实录 |
| 已知限制 | 未解决项 + 影响面（如"图 5 中最小的坐标轴标签在 1600px 渲图下略糊，投影仪可读"） | Stage 5 实录 |

## 3. 可选项（有就写，没有可省）

- 讲稿字数逐页清单（脚本已打印，可整段粘贴）
- 数字溯源表：`数字 → 出处（Table x / Figure x）`，学术/数据类建议附
- 变更说明：相对用户素材做了哪些取舍/补充（删了什么页、合并了什么、为什么）
- `work/` 四个物证文件路径：`deck-spec.json` / `figures.json` / `paper-figures.json` / `qa_output.txt`

## 4. 交付后的免费迭代点

主动邀请用户指出想重做的页，并说明重做粒度：图像式 deck（R3/R4）改一页需重生成该页；R1/R3 可改局部对象；R8 按页重建。**不整体重跑**，除非用户要求换风格或换论证结构。

## 5. 反面样例（这些写法一律视为未交交付说明）

- ❌ "已完成质检，无问题"
- ❌ "已检查讲稿字数、图文覆盖率，均达标"（无原始输出）
- ❌ "图片均来自论文"（无页码/Figure 号/hash 证据）
- ❌ "该页用自己的示意图代替了论文的框架图"（原文有图就必须用原文图，自绘只能补充；G15 会拦）
- ❌ 只贴"QA 通过 ✅"三个字
