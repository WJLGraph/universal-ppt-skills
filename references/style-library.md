# 风格库（Stage 3 按需加载）

> 提炼自 deer-flow ppt-generation（现代风格族）、codex-ppt 风格参考库（中文实用族）、anthropics/pptx + theme-factory（配色板/主题）、nature-paper2ppt（学术克制风）。
> 使用规则（**风格确认门，硬门禁 G12**）：**先按 §1 选择器给出 2-3 个候选 + 每个一句推荐理由 + 你推荐哪个 → 停下等用户确认（STOP-AND-WAIT）→ 确认后锁定并写入 `work/deck-spec.json` 的 `style_name` / `style_confirmed`**。没确认就开渲染 = 流程违规（脚本会把 `style_confirmed=false` 判 FAIL）。若用户明确说"你定就行"，把这句话作为 `confirm_evidence` 抄下来，视为已确认。风格一旦确认，全 deck 保持同一视觉身份，只允许版式按页面角色变化。

## §2 学术克制族

- **学术克制风**（默认学术）：白底，深藏蓝 `1F4E79` 主 + 中蓝 `2E75B6` 辅 + 红强调；单一无衬线字族；白底细线图表；禁装饰图标、禁全幅背景图；figure 左 / 解读右；结论页收尾撑 Q&A。Nature 风（顶刊向）加强版：hero 图占版面 60-75%，解释压缩为窄轨/底条；中文主字族 + 英文数字伴侣字族（最多两个字族）；图带 panel 小标 a/b/c；dark 背景仅用于图片主视觉页。
- **科研答辩风**：面向评审专家的正式汇报。结构规整、信息完整可追溯，常配"课题分解 / 技术路线 / 研究基础 / 风险分析 / 预期成果"模块；蓝白或校徽色系，稳重克制，页脚带页码与汇报人；强调工作量可见性（进度甘特、成果清单）。
- **清爽专业风**：白底 + 单强调色的极简商务学术混合。大留白、细分割线、无装饰；适合答辩、述职、复盘等"内容为王"的正式场合。

## §3 中文实用族（提炼自 codex-ppt 风格库）

| 风格 | 视觉要点 | 典型页面 |
|------|---------|---------|
| **麦肯锡风** | 白/浅灰底、墨蓝灰 `243447` 细线体系；封面/观点页用"巨型重构标题字 + 单一商业隐喻"（漏斗/路径/矩阵/飞轮…），分析页一个核心结构 + 3-6 模块；禁图标海、禁默认圆角卡片阵列 | 框架页、矩阵图、路线图、价值链、五力、2x2 |
| **党政红** | 正红 `C7000B`/深红渐变主色 + 金/白辅助，天安门/华表/旗帜等意象克制使用；标题居中庄重、结构规整对称；红头文件式标题栏 | 工作汇报、党建、年度总结、政策宣讲 |
| **数据仪表盘风** | 深色或浅灰底 + 高亮数据色；KPI 大数字卡、进度环、迷你趋势线；网格化但对齐严格；强调"一眼看到数字" | KPI 汇报、经营分析、监控大盘 |
| **教学课件风** | 明快友好色、大字号、图示化步骤条；每页一个知识点 + 例子 + 练一练；重互动标记（思考/随堂练） | 课程、培训 |
| **手绘白板风** | 白板底 + 手绘线框/箭头/便利贴质感，近黑手写体感标注；弱化精致感强化"一起思考" | 头脑风暴、概念讲解 |
| **手绘技术解释风** | 白底 + 蓝黑手绘示意图，组件用圆角框手绘感，类比配图降低理解门槛；适合技术概念、AI/软件工程 | 技术分享、知识卡片 |
| **复古扁平插画风** | 复古暖色调（芥末/砖橙/墨绿）+ 扁平插画元素、粗颗粒纹理；插画承担叙事 | 文创、文旅、品牌故事 |
| **创意杂志风** | 大胆排版：超大标题字、裁切图、色块碰撞、引言拉排；网格内做打破 | 创意提案、作品集 |
| **温暖手工风** | 米白/奶油底、柔和圆角、纸质感贴纸元素、暖光插画 | 儿童教育、亲子、公益 |
| **电子墨水杂志风** | 类墨水屏的黑白灰 + 单强调色，强排版网格、衬线大标题，纸媒阅读感 | 深度报告、读书会、文集 |

## §4 现代表现族（提炼自 deer-flow，适合 R3/R4 路径）

| 风格 | 色板钩子 | 构图要点 |
|------|---------|---------|
| **glassmorphism** | 紫→青渐变 `667eea→00d4ff`，磨砂白玻璃 15-20% 不透明 | 悬浮玻璃卡 32px 圆角、backdrop-blur、光晕景深；visionOS 气质 |
| **dark-premium** | `0a0a0a` 底 + 电光蓝/霓虹紫/金单强调 | 60%+ 负空间、边缘辉光、电影级打光；奢侈品科技感 |
| **gradient-modern** | Stripe/Linear 式 mesh 渐变 `7c3aed→ec4899→f97316` | 不对称构图、大字标题 80pt+、流体渐变形状；SaaS 新锐感 |
| **neo-brutalist** | 黑白 + 荧光粉/黄/红高对比 | 4-8px 粗黑描边、硬阴影无模糊、破碎网格；Z 世代反叛感 |
| **3d-isometric** | 低饱和紫/青/珊瑚 + 浅灰底 | 30° 等距 3D 插画为 hero、统一光源左上；亲和科技感 |
| **editorial** | 米白 `f5f5f0` + 炭黑 + 酒红/森绿单强调 | 12 栏网格、衬线大标题 96pt、全出血摄影、拉引言；杂志质感 |
| **minimal-swiss** | 纯白 + 纯黑 + 瑞士红/Klein 蓝单强调 | 严格网格、无装饰无阴影、Helvetica 系字阶 12/16/24/48/96；现代主义 |
| **keynote** | 纯黑/深灰 + 白字 + Apple 蓝 `0071e3` | 一页一句话、影院级产品图、极大字号对比；发布会气质 |

R4 生图时把上表钩子写进 prompt（精确 hex、字号、特效参数）；R3 用 CSS 变量落地同一套规格。

## §6 风格工程化规则

1. **深浅三明治**：深色底用于封面 + 结尾页，浅色底用于内容页；或全 deck 深色走高端路线。不要中途随机切换。
2. **每页都要有视觉元素**：图、图表、图标、色块结构任选其一，纯文字页必败。
3. **风格确认门**：给出 2-3 个候选 + 一句推荐理由 → 用户确认 → 锁定进视觉规格卡（design-language.md §8）。R4 路径先出 1 页样张确认后再批量。
4. **风格复用**：用户确认的规格卡可存入风格库（如 `~/.workbuddy/skills/universal-ppt-skill/styles/`），下次同名场景直接调用；用户提供的品牌色/模板色优先于一切默认色。
5. **自定义风格**：没有合适预设时，按"色板（hex）+ 字族搭配 + 母题元素 + 明暗基调"四件套现场生成一个命名风格，给用户预览确认后按 §4 钩子方式写进规格卡。
