# 质检门禁（Stage 5 按需加载）

> 第一版渲染几乎必有真实缺陷。质检不是走过场，是交付前最后一道闸。

## §1 内容质检

- [ ] 逐页标题是 action title（学术模式内容页 100% 结论式）
- [ ] Ghost deck 测试通过：只读标题能讲通全篇
- [ ] 术语台账核对：模型名/数据集/指标/缩写逐字一致（含讲稿）
- [ ] 无遗留占位符/示例文字（搜索 XXX、lorem、TODO、[insert、"此处"）
- [ ] 无编造内容：每条关键结论可溯源；无法溯源的已标"需人工核实"
- [ ] 页数与大纲一致；该有的页都在（结论页、References 页）
- [ ] 讲稿齐全且长度合规（80-120 字/页）

## §2 视觉质检（渲染成图片逐页看）

优先级顺序（先修高级别）：

1. **文字溢出/截断**（最常见缺陷，永远用户可见）
2. 元素重叠（文字压形状、线条穿字）
3. 对齐与间距（同类元素未对齐、间距不均、块间 <0.3"、贴边 <0.5"）
4. 对比度（浅字浅底/深字深底，图标无对比底）
5. 版式重复（连续三页同一版式；slide-sorter 扫描 5 页以上同构图）
6. 图表裸奔（无标题/无标签/默认配色）
7. AI 味反模式（对照 design-language.md §6 逐项扫）
8. 中文去模板化短语（对照 design-language.md §7 清单扫）

**严重度分级**（蒸馏自 nature-paper2ppt）：

- **high（阻断交付）**：证据被裁切（坐标轴/图例/panel 标签/表格行）、关键结果页主证据不可读、文字溢出或被裁、页序错乱或缺核心证据、编造的量化表述
- **medium**：过密页、AI 模板味版式（重复等分卡片/清一色右轨/装饰指标行）、裁切边缘过紧、图注脱离视觉、讲稿缺失或无用、来源归属含糊
- **low**：轻微对齐瑕疵、色板/字体微调、可读但密图未拆

处理规则：high 全修；medium 修掉不显著扩大工作量的；low 记录可不修。修完重渲复查，连续一轮无新缺陷即停（不无限打磨）。

**程序化检查清单**（生成栈允许时在渲图前先跑，蒸馏自 nature-paper2ppt + anthropics validate）：

- 形状边界：所有 shape 的 left/top/right/bottom 是否在画布内
- 文本溢出估算：字符数 vs 容器宽高（中英混排最易爆），长 token 重点查
- 近似对齐检测：多对象边缘差几像素的"没对上"
- 布局重复计数：同一构图复用次数
- 媒体与 notes 计数：图片数、notes 覆盖率
- 占位符扫描：lorem、xxx、TODO、未替换标签
- 图像裁切参数可疑值、主证据图过小（低于页面 1/4 需人工确认）

**渲染预览政策**：渲图流程（LibreOffice→PDF→pdftoppm→逐页看图）；修改后必须从改过的 PPTX 重新走完整转换链，不能复用旧图。无可靠渲染器的环境降级为：程序化检查 + 资产裁剪拼图检查 + 逐页文本/形状审查，并在交付说明中注明"渲染预览不可用"。

图像式 PPT（R3/R4）追加：图像内文字是否幻觉/错字（不可编辑，只能重生成）；页面编号/水印是否意外出现。R8 追加：重建页与原图并排对比（contact sheet），结构无遗漏、无新增幻觉元素、箭头/公式为原生对象。

字体注意：QA 渲染器的字体替换与真实打开环境不同——用安全字体（Calibri/Arial/微软雅黑等）做容器宽度计算，非安全字体留 10% 宽度余量（安全清单见 design-language.md §2）。

## §3 溯源质检（学术/数据类必做）

- [ ] 两遍法执行：主张清单先经用户确认，再逐条核验
- [ ] 每条关键结论标注 (来源, 位置, 强度)
- [ ] 借用图表在页内有 in-slide citation（作者/venue/年份小字），References 页有完整条目
- [ ] 引用格式统一（GB/T 7714 / APA / IEEE 按用户要求）
- [ ] 统计类主张核验：样本量、显著性检验、误差线、对照设置、是否过度推断
- [ ] 复现类内容核验：环境依赖、运行命令、数据来源与论文描述一致

## §4 交付清单

1. 交付物：主文件（.pptx / .pdf / .html / .zip）+ 讲稿（嵌入 notes 或独立 .md）
2. present_files 展示；说明页数、模式（A-F）、风格名、渲染路径、QA 结果（严重度统计）、已知限制
3. 附变更说明：相对用户素材做了哪些取舍/补充
4. 提供一次免费迭代点：邀请用户指出想重做的页（局部重做优先于整体重生成——图像式 deck 改一页重生成，R1/R3 改局部，R8 按页重建）
5. 用户确认风格后，将视觉规格卡存入技能风格库（`~/.workbuddy/skills/universal-ppt-skill/styles/`），下次直接复用
